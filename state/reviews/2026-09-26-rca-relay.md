# Root cause: no runner report ever reached the arming session

Written 2026-09-26 by the arming session (`session_01YGq4H9eezU7hawFM3bRgE2`)
during the attended weekly review.

## What happened

Each Friday firing ended by calling `fire_trigger` on a poke-only trigger bound
to the arming session (`trig_01DcJrhKop6mfes4uutV3ChR`). None of the reports
arrived: not the two rehearsals, not the F-1 test, not the close. The trigger
recorded **no run at all**. The watchdogs, which were one-shot `run_once_at`
triggers bound to the same session, did arrive.

## Root cause (measured)

**`fire_trigger` does not deliver into the trigger's bound session. It starts a
new one.** On 2026-09-26 the arming session fired the relay itself. The result
named a different session, `cse_01PBWGY85GTiqaHCNGa7QPnS`, and that session's
record reads `origin: force_run_trigger`, with no repository and no connection
to the arming session. So every runner report went to a fresh, repo-less
session that nobody reads. That test session is now archived.

**Scheduled delivery works.** A trigger with `run_once_at` bound to a session
delivers into that session. This is the path the watchdogs used, and the one
the week's per-day runners were driven by.

The runners never noticed, because each one wrote its report file **before**
calling `fire_trigger` and never recorded the call's result.

## Fix

- **Report back by schedule, not by force-run.** The runner creates a one-shot
  trigger with `create_trigger`, with `persistent_session_id` set to the
  arming session, `run_once_at` two minutes out, and the report as the
  prompt. This is the same mechanism the watchdogs proved.
- **Record the post-back result in the committed report.** That means a
  second commit after the call, or at least the watchdog confirming it. A
  step whose outcome is never written down cannot be found broken.
- The committed report file stays the source of truth, and the watchdog
  stays the backstop. On Friday, that backstop is the only reason the day
  was visible at all.
- The poke-only relay trigger is deleted.

Shape (docs/04-lessons.md): **D, a control that is correct in isolation and
never receives the state that makes it bind.** Each half worked (the runner
called the tool, the trigger existed), and the delivery between them never
happened.

## G-5 — why every Opus 5.5 turn read "medium" (arming session, 2026-09-29)
Claude Code documentation (https://code.claude.com/docs/en/model-config,
fetched 2026-09-29): Opus 5.5's default effort is `medium`, and a session's
effort resolves as (1) an explicit choice (`CLAUDE_CODE_EFFORT_LEVEL`,
`--effort`, `/effort`), then (2) settings, then (3) the model default. The
settings reference (https://code.claude.com/docs/en/settings-reference) says a
level is saved per model under `modelSettings`, and that a top-level
`effortLevel` in USER settings is ignored by Opus 5.5. So a turn with no pick
and no per-model setting runs at `medium`, which is every G-1/G-4 reading.
Fix, short term: `.claude/settings.json` now carries `modelSettings` at
`xhigh` for claude-opus-5-5, claude-opus-5 and claude-sonnet-5. It is untested
in a cloud session until the live test (task 6) reports. Stronger, if it does
not bind: `CLAUDE_CODE_EFFORT_LEVEL=xhigh` in the environment's variables
(precedence 1), which only recalcitrantmaus can set.
